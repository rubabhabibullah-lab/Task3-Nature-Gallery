PASTEL PURPLE GALLERY WEBSITE

1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser (or use Live Server).
4. Click Explore Gallery to open the separate gallery page.
5. Use category filters and click any photo to open the lightbox. Use arrow buttons or keyboard arrows to browse.

Images load from Unsplash, so an internet connection is needed to display them.
